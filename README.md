## ▶️ How to Run Tests

### Install dependencies

```bash
npm install
```

### Run all tests

```bash
npx playwright test
```

### Run a specific test

```bash
npx playwright test tests/WebApiPart_1.spec.js
```

### Run tests in debug mode

```bash
npx playwright test --debug
```

### View HTML report

```bash
npx playwright show-report
```
